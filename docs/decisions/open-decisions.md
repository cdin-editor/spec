# Legacy Open Decisions pointer

This path is retained for historical links. The canonical Open Decisions Register is [`docs/adr/open-decisions.md`](../adr/open-decisions.md).

The current canonical register records OD-22, OD-23 and OD-24 as resolved by [ADR-0018](../adr/ADR-0018-frontend-protocol-wire.md), and OD-32 as resolved by [ADR-0019](../adr/ADR-0019-runtime-bridge.md). Historical statuses in this legacy directory are not authoritative.
