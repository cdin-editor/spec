# Legacy decision pointer — no shared repositories

This file is retained for old links only. The canonical decision is [ADR-0014](../adr/ADR-0014-no-shared-repositories.md) in the current ADR directory.

The reference protocol codec's location is no longer open: [ADR-0018](../adr/ADR-0018-frontend-protocol-wire.md) places the independently linkable `cdin_protocol` C target in the Backend repository. No `cdin-shared`, `cdin-common` or separate protocol repository is created.
